# Keep alerts on screen

macOS shows notifications as **Temporary** banners by default, which disappear after a few seconds. If you step away, you might miss that Claude needs you.

In System Settings › Notifications › **CC Beacon**, set the alert style to **Persistent**. Banners then stay on screen until you click or dismiss them.

CC Beacon removes its own notifications once you've seen the session, so persistent banners don't pile up.
