# Allow notifications

CC Beacon shows macOS notifications through a small helper app named **CC Beacon**.

1. Click **Send Test Notification**. macOS asks once whether CC Beacon may send notifications: choose **Allow**.
2. Click the test notification when it appears. VS Code asks once whether CC Beacon may open the link: tick **Don't ask again** and choose **Open**.

After that, clicking any CC Beacon notification brings you back to the right window and the right Claude session.

If you chose Don't Allow by mistake, open System Settings › Notifications › CC Beacon and turn on **Allow notifications**.
